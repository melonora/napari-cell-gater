# napari-cell-gater

A napari plugin to perform cell marker gating for multiplexed immunofluorescent imaging.

`napari-cell-gater` is part of the [openDVP](https://github.com/CosciaLab/openDVP)
ecosystem ([documentation](https://coscialab.github.io/openDVP/)).

Installation, input requirements and the step-by-step gating walkthrough live in the
project README, which is the single source of truth:

<https://github.com/CosciaLab/napari-cell-gater#readme>
